Reports risky or incorrect Spring Data @Query declarations.
  • Missing @Param – a named bind parameter such as :name has neither a matching @Param("name") nor a method parameter literally named name. Binding fails at runtime unless the project is compiled with -parameters. A quick-fix adds the annotation when the target parameter is unambiguous.
  • SpEL injection surface – the query embeds a SpEL expression (#{...}). These can interpolate untrusted input — for example a dynamic ORDER BY in a native query — and should be reviewed.
  • String concatenation – the @Query value is assembled with + instead of a single string literal. Flagged by default; disable via the Allow building the @Query value with string concatenation option. Java requires the operands to be compile-time constants, so this is a style check rather than a security one.

Each check can be toggled in the inspection options.
