Reports Spring Data repository methods that return an unbounded collection (List, Set, Collection, Iterable or Stream) with no pagination. Such methods can load an entire table into memory and degrade performance as data grows.

A quick-fix changes the return type to Page<T> and appends a Pageable parameter.

The warning is suppressed when the method:

  • already takes a Pageable or Sort argument;
  • returns Page or Slice;
  • is name-limited, e.g. findFirstBy… / findTop10By…;
  • declares a @Query that already contains a LIMIT clause.

By default only "find all"-style methods (whose name contains an All segment) are reported; disable that option to flag every unbounded query.

By default RepoBuddy runs in panel-only mode: these findings appear in the RepoBuddy Issues tab, the editor banner, and the status-bar counter rather than inline. Disable panel-only mode under Settings | Tools | RepoBuddy to see them as ordinary editor warnings.
