Reports methods that write to the database without transactional context.
  • @Modifying without @Transactional – a Spring Data @Modifying query method that is neither annotated @Transactional nor declared in a @Transactional class throws at runtime unless every caller already runs inside a transaction.
  • EntityManager writes – a method body that calls persist, merge, remove, flush, or Query.executeUpdate() outside a transaction throws TransactionRequiredException.
  • Repository write calls (opt-in) – a method that calls repository save/delete/update operations without @Transactional; helpful when several writes must commit atomically.

A quick-fix annotates the method with @Transactional. Both Spring and Jakarta/javax @Transactional annotations are recognised as satisfying the requirement.

Private methods are ignored by default because Spring's proxy cannot apply @Transactional to them; static methods are always skipped.
