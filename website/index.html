✦ Features

Everything you need,
nothing you don't

Six powerful capabilities built into IntelliJ — no REST client, no test file, no restart needed.

⚡
Instant Repository Runner
Click the ⌕ gutter icon next to any Spring Data JPA method to run it against your live app. Real JPA context, real database, real results — no test file, no restart.
🔍
SQL Transparency
Every Hibernate statement triggered by your call is intercepted, ordered, and timestamped via StatementInspector. N+1 problems have nowhere to hide.
🎲
Smart Parameter Input
Type-aware input widgets generated per parameter — String, UUID, LocalDate, Pageable, Enum, List<Long>, and 24 more. Hit "Generate All" for instant realistic test data.
🌿
Call Chain Tracer
Pick any Spring MVC endpoint and trace every repository method it touches. Results render as an expandable tree with HTTP method badges, @Transactional markers, and double-click navigation.
📊
Repository Usage Analytics
Call-count badges across your whole project — green (hot), amber (rare), red (never called). Filter by file, toggle "Show Unused Only", and export to CSV in one click.
🛡️
Code Inspections
Five inspections catch N+1 queries, missing @Transactional, unsafe @Query, self-invocation, and unbounded result sets — surfaced in the Issues panel, not as noisy editor underlines.

✦ Installation

Get started in one click

Install from JetBrains Marketplace in seconds, or build from source with Gradle.

  1. Open IntelliJ IDEA
  2. Go to Settings → Plugins → Marketplace
  3. Search for RepoBuddy
  4. Click Install and restart
  5. Open your Spring Boot project — gutter icons appear automatically ✓
# Clone the repository
git clone https://github.com/ELglaly/Repo-Buddy.git
cd RepoBuddy

# Build the plugin ZIP
./gradlew buildPlugin

# Or launch a sandboxed IntelliJ instance
./gradlew runIde

Built ZIP appears in build/distributions/. Install via Settings → Plugins → Install Plugin from Disk.

✦ FAQ

Common questions

Does RepoBuddy work with Spring Boot 3.x and the Jakarta namespace? +
Yes. RepoBuddy supports Spring Boot 2.7.x, 3.x, and future 4.x releases. It ships both a spring.factories file and a .imports file so the embedded agent auto-configures on all supported versions. Both Spring and Jakarta @Transactional are fully recognised.
Will it add dependencies or files to my project's build? +
No. RepoBuddy's agent JAR is embedded inside the plugin JAR and extracted to your system temp directory at runtime. Nothing is added to your pom.xml or build.gradle. The -javaagent flag is injected only into IntelliJ run configurations and is automatically cleaned up when you uninstall the plugin.
Is RepoBuddy free? Are there any paid tiers? +
RepoBuddy is completely free and open-source. No paid tiers, no usage limits, no feature gates. The full source is on GitHub — contributions are welcome.
